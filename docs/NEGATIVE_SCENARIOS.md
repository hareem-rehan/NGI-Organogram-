# Negative Scenarios Catalog — Dynamic Organogram Manager

Master reference of negative and boundary scenarios. Each phase in `docs/IMPLEMENTATION_PLAN.md` pulls the subset relevant to it; this file is the exhaustive catalog so nothing gets lost between phases. Every scenario should map to at least one automated test layer per `docs/TEST_STRATEGY.md`; where automation genuinely isn't practical, that's stated explicitly with a reason (never silently skipped).
